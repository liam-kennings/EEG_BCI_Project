# Why This Project Poster Visual

This square, circular panel is the recommended visual replacement for an
abstract on the physical poster. It emphasizes the clinical motivation,
patient-specific challenge, safety requirement, and potential applications
without repeating the full methods or results sections.

- `00_why_this_project.png`: 300-DPI raster export for poster software.
- `00_why_this_project.svg`: editable vector export.
- `00_why_this_project.pdf`: print-ready vector export.

Regenerate all formats with:

```bash
python scripts/43_create_v7_poster_why_visual.py
```

The full and short written abstracts remain in the poster content document for
conference submission forms or an accompanying report.
