# EEG BCI Project Dataset Citations

This sheet covers datasets that were actually loaded and analyzed in this
project. It intentionally excludes datasets that appeared only in literature
reviews or future-work recommendations.

For a single section that can be pasted directly into the poster, use
[EEG_BCI_POSTER_REFERENCES_DROP_IN.md](EEG_BCI_POSTER_REFERENCES_DROP_IN.md).

## Citation Scope

| Dataset | Project role | Include on the V7 poster? |
|---|---|---|
| PhysioNet EEGMMIDB | Core V7 development and evaluation | Yes |
| OpenBMI | Core V7 development and evaluation | Yes |
| Liu acute-stroke EEG | Core V7 development and evaluation | Yes |
| MRCP EEG-EMG hand gestures | Auxiliary EMG-supervised transfer experiment | Only if that experiment is shown |
| WAY-EEG-GAL | Auxiliary privileged-transfer and EEG-only pretraining experiments | Only if that experiment is shown |
| HS-Stroke | Separate locked chronic-stroke evaluation | Only if that evaluation is shown |

## Usage Note

Dataset citations acknowledge data creation and access; they do not replace
citations for preprocessing or decoding methods. If space is limited, retain
the three core V7 dataset citations on the poster and place this full reference
sheet behind a QR code or in the accompanying report.
